# directional-blur-transition

Digital slow-shutter whip transition for short-form video. One Python script, no plugins.

```bash
python3 scripts/wipe.py a.mp4 b.mp4 out.mp4 --duration 0.5 --angle 0 --sfx
```

See SKILL.md for options. Works as a Claude Code skill (symlink the folder into `~/.claude/skills/`).
